Build an AI Study Assistant App — StudyPilot

I want to build a modern, professional AI-powered study assistant called StudyPilot, designed primarily for students aged 14–19.

1. Main purpose

The app should help students prepare for school tests and exams more effectively.

The main idea is simple:

Students upload their study materials (PDFs, photographs of textbook pages or written notes), and AI analyses the content and turns it into personalised learning materials.

The app should help students understand what they know, identify their weaknesses and improve their results.

2. Main features

A. Upload study materials

* Allow users to upload PDF files, photographs and text.
* Extract and understand information from the uploaded materials.
* Organise materials by subject.
* Allow users to name and save their study topics.

B. AI test generator

* Generate tests based on the uploaded materials.
* Include multiple-choice questions, true/false questions and open-ended questions.
* Allow users to choose difficulty: Easy, Medium or Hard.
* Let users choose the number of questions.
* Give immediate feedback after each answer.
* Explain why an answer is correct or incorrect.

C. Flashcards

* Automatically create flashcards from uploaded materials.
* Show a question on one side and its answer on the other.
* Allow users to mark cards as easy or difficult.
* Prioritise cards that users frequently get wrong.

D. Personalised learning

* Track the user’s test results.
* Remember incorrect answers.
* Generate additional questions based on weak areas.
* Show progress over time.
* Recommend what the student should study next.

E. Dashboard

Create a clean dashboard showing:

* Welcome message.
* Recently studied subjects.
* Upcoming tests.
* Recent test results.
* Learning progress.
* Quick access to uploaded materials, tests and flashcards.

3. Design and appearance

I want a premium-looking, modern and minimalist interface.

Design inspiration:

* Duolingo’s simplicity.
* Notion’s clean layout.
* Modern AI productivity applications.

Use:

* White or very light grey backgrounds.
* Dark navy or black text.
* A subtle blue or purple accent colour.
* Rounded cards.
* Clean typography.
* Simple icons.
* Smooth animations.

The app must look professional and be easy to use on both phones and computers.

4. Navigation

Create these main sections:

1. Dashboard
2. My Materials
3. AI Test Generator
4. Flashcards
5. My Progress
6. Settings

5. Monetisation

Build a freemium subscription model.

Free plan:

* Limited monthly AI-generated tests.
* Limited uploaded materials.
* Basic flashcards.
* Basic progress tracking.

Premium plan — €4.99/month:

* More AI-generated tests.
* More uploaded materials.
* Unlimited flashcards.
* Personalised learning recommendations.
* Advanced progress tracking.

Include a pricing page, but do not activate real payments yet.

6. Technical requirements

* Build a functional application, not just a static design.
* Use a database to save user accounts, materials, flashcards and test results.
* Implement secure authentication.
* Integrate an AI model to analyse materials and generate questions.
* Make the upload system functional.
* Ensure the app works on mobile and desktop.
* Keep the code organised and scalable.

Use secure server-side API calls and never expose secret API keys in the frontend.

7. Important instructions

Start by building a working MVP with the essential features rather than trying to build every advanced feature immediately.

Prioritise:

1. User registration and login.
2. Uploading study materials.
3. AI-generated tests.
4. Answer checking and explanations.
5. Flashcards.
6. Saving and tracking progress.

Use realistic sample data where backend functionality is not yet connected. Clearly identify any features that are still demonstrations rather than working features.

The final product should feel like a real commercial education application that could eventually serve thousands of students.
